# 함해보카 (HamHaeVoca)

Android에서 개인 단어장을 만들고, Excel 파일을 가져와 낱말카드·시험·맞추기로 반복 학습하는 어휘 학습 앱입니다.

> **문서 기준:** 2026-11-10에 제공된 `HamHaeVoca_Final_Integrated_src.zip`에 `HamHaeVoca_Favorites_Pin_UI_Refinement_src.zip`과 `HamHaeVoca_Fixed_Default_Favorites_Order_src.zip`을 순서대로 적용한 소스 패치. GitHub 반영, Android 전체 빌드 성공 또는 실기기 검증을 의미하지 않습니다.

## 2. 주요 기능

- **단어장 관리:** 생성, 가져오기, 갱신, 검색, 단어장/폴더 개별 정렬, 폴더 생성·이름 변경·삭제.
- **다중 선택:** 단어장 여러 개 선택 후 폴더 이동·삭제·즐겨찾기·상단 고정·선택 취소. 삭제 전 확인.
- **단어 관리:** 단어·뜻·Day·Category 및 예문 관리; 암기/미암기 상태, 정답/오답 횟수 기반 오답률 표시.
- **학습:** 낱말카드, 객관식·품사 시험, 맞추기, 시험 결과와 오답 기록.
- **학습 조건:** 단어 수, 시간, 최소 오답 횟수 등 해당 화면의 설정 사용.
- **언어:** 한국어, 영어, 프랑스어, 스페인어, 베트남어, 일본어, 중국어(간체)의 앱 UI 지원을 목표로 함. **단어장 데이터는 자동 번역하지 않음.**

### UI 원칙

기존 HamHaeVoca의 카드·색상·레이아웃을 유지합니다. 삼성 노트는 주로 검색 노출, 폴더, 사이드 메뉴의 **조작 방식**만 참고합니다. 사용자가 지정하지 않은 아이콘과 장식을 추가하지 않습니다. 메인 화면의 추가 버튼과 선택된 단어장 카드 테두리는 민트색을 사용하며, 선택 테두리는 한 겹입니다. 즐겨찾기/상단 고정은 선택 모드에서만 변경하며 카드의 별/핀은 상태 표시 전용입니다.

### HOME-02 — 햄버거 메뉴와 폴더 정렬

폴더 영역은 **모든 단어장 → 기본 → 즐겨찾기 → 사용자 생성 폴더** 순서로 표시합니다.

- **기본**과 **즐겨찾기**는 실제 폴더 정렬 방식과 무관하게 해당 위치에 고정됩니다.
- **즐겨찾기**는 가상 폴더입니다. 즐겨찾기로 지정한 단어장을 자동으로 모아 보여주되, 기존 실제 폴더 소속은 변경하지 않습니다.
- **사용자 생성 폴더만** 폴더 정렬 대상이며, 이름순·이름 역순·생성순(오래된 순)·생성순(최신 순)을 지원합니다.
- 사이드 메뉴 설정 이름을 **단어장 정렬**과 **폴더 정렬**로 분리하고, 폴더 정렬을 단어장 정렬 **바로 아래**에 둡니다.
- 폴더 생성·수정·삭제 시 열린 메뉴를 갱신하도록 구현했습니다. 메뉴의 폴더별 숫자는 현재 해당 단어장 수를 나타냅니다.

### HOME-04 — 즐겨찾기와 상단 고정

단어장 선택 모드의 작업 아이콘 순서는 **폴더 이동 → 삭제 → 즐겨찾기 → 상단 고정 → 선택 취소**입니다. 단어장 카드 우상단을 직접 터치하는 방식으로 즐겨찾기를 변경하지 않습니다.

- 하나 이상의 단어장을 선택하여 즐겨찾기 또는 상단 고정을 **일괄 설정/해제**할 수 있습니다.
- 선택 집합에 미설정 단어장이 하나라도 있으면 모두 설정하고, 전부 설정된 상태에서 누르면 모두 해제합니다.
- 상단 고정된 단어장은 **고정한 순서**대로 목록 맨 위에 배치되며 일반 단어장은 지정된 단어장 정렬을 따릅니다.
- 카드에는 **설정된 상태만** 표시합니다. 즐겨찾기 OFF면 별표가 없고, 고정 OFF면 핀도 없습니다.
- 카드의 즐겨찾기는 둥근 노란색 별 벡터 아이콘, 고정은 흑백 단색 벡터 아이콘을 사용합니다. 최근 수정에서 기존 대비 약 80% 크기로 조정했습니다.
- BOOK-01에서는 상단 고정 아이콘을 표시하지 않습니다. 즐겨찾기된 경우에만 **제목 문자열 바로 뒤**에 둥근 노란색 별 아이콘을 표시하며, 별은 버튼이 아닌 표시용입니다.


## 4. 지원 단어장 / Excel 데이터 형식

TXT, CSV, TSV, XLSX 파일 입력을 지원하도록 설계되어 있습니다. **가져오기 미리보기의 단어 인덱스는 Excel 행 번호가 아닌 1부터 시작하는 단어 순번**입니다.

### Unit4 — 일반 단어장

| 열 | 필드 |
|---|---|
| A | Vocabulary |
| B | Mean |
| C | Day |
| D | Category |

### Conj — 예문형 단어장

| 열 | 필드 |
|---|---|
| A | Vocabulary |
| B | Mean |
| C | Day |
| D | Category |
| E | Example (선택) |

예문이 있는 단어는 낱말카드에서 정답을 확인한 후 얇은 구분선 아래에 예문을 표시합니다. 예문이 없으면 기존 카드 기능은 유지합니다.

### Verb — 동사 3단 변화형 (신규)

`CCI_Voca_Verb.xlsx` 형식에 대응합니다.

| 열 | 필드 | 예시 |
|---|---|---|
| A | 현재형 (Present) | begin |
| B | 과거형 (Past) | began |
| C | 과거분사 (Past Participle) | begun |
| D | 뜻 (Meaning) | 시작하다 |
| E | Day | Day 값 |
| F | Category | 분류 값 |

동사형 데이터를 위한 `past`, `pastParticiple` 필드가 모델/DB에 추가되었으며, 해당 값이 있는 단어에서 Verb 카드 흐름을 사용합니다. **Verb 형식의 Example 열은 현재 제공된 Excel 구조에 포함되어 있지 않습니다.**

## 5. 낱말카드 동작

| 카드 유형 | 터치/Flip 단계 |
|---|---|
| Unit4 | 단어 ↔ 뜻 (기존 방식) |
| Conj | 단어 ↔ 뜻, 정답 확인 후 예문 표시 |
| Verb | **현재형 → 과거형 → 과거분사 → 뜻** |

Verb 카드의 경우 **총 3회의 Flip 후 뜻**이 표시됩니다.

```text
begin        (첫 화면, 예문 영역: 1)
  ↓ Flip 1
began        (예문 영역: 2)
  ↓ Flip 2
begun        (예문 영역: 3)
  ↓ Flip 3
시작하다       (뜻, 단계 번호 없음)
```

**Verb 단계 번호는 단어 본문이나 시험 문제에 붙지 않고 낱말카드의 예문 영역에만 표시**합니다. 기존 Excel에 Example 값이 없더라도 `1`, `2`, `3`이 표시됩니다. 예문 텍스트가 있을 경우 `1. 예문`처럼 표시하도록 처리한 코드입니다. 단어·뜻·예문의 글자 크기 설정은 전역 설정으로 저장합니다.

## 6. 시험과 맞추기

시험 설정은 기존 출제 방식 선택을 2×2 배열로 표시하며, `품사 태그 복수 선택` 대신 `품사 선택`이라는 용어를 사용합니다. 시험 설정의 뒤로가기 UI는 다른 학습 설정 화면과 통일합니다.

Verb 단어 시험은 **현재형 외에 과거형·과거분사형도 문제에 사용할 수 있게** 확장되었습니다. 단, 최근 수정에 따라 시험 문제에 표시되던 `[2 · past]` 등의 **형태 인덱스**와 `Meaning Hint` / `English word hint` 문구는 삭제합니다. 이는 낱말카드 예문 영역의 `1·2·3` 표시와 다른 요구사항입니다.

맞추기 설정 안내 문구는 `사용할 단어 수와 주어지는 시간을 선택하세요`로 통일합니다. 기존 맞추기 로직을 Verb의 세 형태별 개별 문제로 확장했다는 뜻은 아닙니다.

## 7. 오답률 계산 및 데이터 보존

단어장 내부의 단어 목록에서는 별도 `암기`, `시험 1회`, `오답 1회` 등의 상태 뱃지 대신 **`오답률 XX%`**만 표시합니다. 이 수치는 뜻과 같은 행의 오른쪽에 배치하도록 수정한 이력이 있습니다.

계산식: **오답 횟수 ÷ (정답 횟수 + 오답 횟수) × 100**. 아직 응답 기록이 없을 때의 표시값은 구현을 확인해야 합니다. 최근 패치에서는 낱말카드에서 암기로 판정한 경우도 정답 횟수로 누적하도록 변경했습니다. **과거에 누락된 정답 기록은 자동 복원되지 않습니다.**

### 데이터 보존 및 마이그레이션

- 기존 단어장, 단어, 암기 상태, 정답/오답 횟수, 시험 기록 및 폴더 데이터를 보존하는 것이 최우선입니다.
- Verb 지원에서 DB 버전이 4로 올라갔고, **즐겨찾기(`favorite`)와 상단 고정 순서(`pin_order`) 추가로 현재 DB 버전은 5**입니다. 기존 설치의 v1~v4에서 v5로 업그레이드할 때 기록 보존 여부를 확인해야 합니다.
- `favorite`는 초기값 0, `pin_order`도 초기값 0이며, 고정 시 순차적으로 증가하는 순서 값을 기록합니다.
- 단어장을 갱신할 때 학습 기록이 무조건 초기화되지 않도록 동일 단어 판별 및 갱신 정책을 검토해야 합니다.
- 데이터 백업 없이 앱 데이터를 삭제하거나, DB를 삭제하고 재설치하여 마이그레이션을 대신하지 마세요.

## 10. 빌드 및 실행

1. Android Studio에서 **프로젝트 루트**(`settings.gradle` 등이 있는 폴더)를 엽니다.
2. Gradle 동기화를 진행합니다. Android SDK 및 프로젝트 Gradle 플러그인에 맞는 JDK를 사용합니다.
3. 에뮬레이터 또는 기기(API 21 이상)를 선택합니다.
4. `app` 실행 구성을 선택하여 빌드 및 실행합니다.
5. 기존 데이터를 가진 기기에서는 먼저 백업 후 DB 마이그레이션과 업데이트 경로를 테스트합니다.

### Windows APK 빌더 사용 시

프로젝트 루트의 `Build_HamHaeVoca_Latest.bat`은 Gradle의 `:app:clean` 및 `:app:assembleDebug --rerun-tasks`를 실행하고, 빌드된 Debug APK를 **배치 파일이 있는 폴더에 복사**하도록 제공된 도구입니다. **빌더는 최신 패치 ZIP을 자동으로 적용하지 않습니다.** 최신 소스를 `app/src/`에 먼저 덮어쓴 뒤 실행해야 합니다. Debug APK는 배포용 서명 Release APK가 아닙니다. 배치 파일의 실제 Windows 실행 결과는 별도 확인이 필요합니다.

### 가져오기 UI

직접 내용 붙여넣기, 구분자 선택(자동·탭·쉼표), 미리보기/초기화 **버튼**은 제거하고 파일 선택 이후 자동 분석 및 결과 표시는 유지하도록 수정했습니다. 파일 선택 버튼은 민트색입니다. **세 번째 열을 Day로 사용**을 끄면 Day 선택 버튼과 관련 설명을 숨기는 것이 현재 요구사항입니다.

### 전달 패치 적용 시

제공되는 코드 패치 ZIP의 최상위 폴더는 `src/`입니다. 그 안의 **변경된 파일만** 기존 `app/src/`에 덮어씁니다. 과거 ZIP을 무작정 다시 덮어쓰면 이후 개선 사항을 되돌릴 수 있습니다. **README는 코드 패치의 `src/`가 아니라 저장소 루트의 `README.md`**에 위치합니다.
